"
Color a graph with 4 vertices and 3 colors, such that connected vertices have different colors.

The following vertices are connected (undirected planar graph):
    A <-> B
    B <-> C
    B <-> D
    C <-> D

The color of a vertex is a function: the unknowns color(v, c) state that vertex v has color c.

Run with:
    rsbdd examples/graph_coloring.txt -t -ft
"

vertex(A) -> true;
vertex(B) -> true;
vertex(C) -> true;
vertex(D) -> true;

is_color(Red) -> true;
is_color(Green) -> true;
is_color(Blue) -> true;

edge(A, B) -> true;
edge(B, C) -> true;
edge(B, D) -> true;
edge(C, D) -> true;

"Every vertex has exactly one color"
forall v # vertex(v) => exists c # is_color(c) & color(v, c) & forall c2 # is_color(c2) & color(v, c2) => c2 = c;

"Connected vertices have different colors"
forall v, w, c # edge(v, w) & is_color(c) => -(color(v, c) & color(w, c))
